# Vercel Environment Variables Setup

## Quick Setup via Vercel Dashboard

1. Go to your project on [vercel.com](https://vercel.com)
2. Navigate to **Settings** → **Environment Variables**
3. Add the following variables:

### Required Variables

| Variable Name | Value | Environment |
|--------------|-------|-------------|
| `VITE_SUPABASE_URL` | `https://your-project.supabase.co` | Production, Preview, Development |
| `VITE_SUPABASE_ANON_KEY` | Your Supabase anon key | Production, Preview, Development |

### Optional Variables

| Variable Name | Example Value | Environment |
|--------------|---------------|-------------|
| `VITE_SHOPIFY_DOMAIN` | `your-store.myshopify.com` | Production, Preview |
| `VITE_SHOPIFY_STOREFRONT_TOKEN` | Your storefront token | Production, Preview |
| `VITE_RADIOKING_BASE` | `https://api.radioking.io` | All |
| `VITE_RADIOKING_SLUG` | `your-radio-slug` | All |
| `VITE_AZURACAST_API_BASE` | `https://your-instance.com` | All |
| `VITE_AZURACAST_API_KEY` | Your AzuraCast key | Production, Preview |
| `VITE_TELEGRAM_BOT_TOKEN` | `123456:ABC-DEF...` | Production |
| `VITE_TELEGRAM_MOD_CHAT_ID` | `-1001234567890` | Production |
| `VITE_WEBHOOK_SECRET` | Random secret string | Production |
| `VITE_MAKE_WEBHOOK_CARE` | `https://hook.make.com/...` | Production |
| `VITE_MAKE_WEBHOOK_EARN` | `https://hook.make.com/...` | Production |
| `VITE_ANALYTICS_ID` | Your analytics ID | Production |
| `VITE_WEATHER_API_BASE` | `https://api.open-meteo.com` | All |
| `VITE_LINK_SIGNING_SECRET` | Random secret string | Production |

## Quick Setup via Vercel CLI

```bash
# Install Vercel CLI if not already installed
npm i -g vercel

# Login
vercel login

# Link to your project
vercel link

# Add environment variables
vercel env add VITE_SUPABASE_URL production
# Paste your value when prompted

vercel env add VITE_SUPABASE_ANON_KEY production
# Paste your value when prompted

# Repeat for all required variables...

# Pull env vars to local for testing
vercel env pull .env.local
```

## Bulk Import via Vercel CLI

Create a file called `vercel-env.txt`:
```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
VITE_SHOPIFY_DOMAIN=your-store.myshopify.com
VITE_SHOPIFY_STOREFRONT_TOKEN=your-token
# ... add all your variables
```

Then import:
```bash
cat vercel-env.txt | while IFS='=' read -r key value; do
  [[ "$key" =~ ^#.*$ ]] && continue
  [[ -z "$key" ]] && continue
  echo "Setting $key..."
  vercel env add "$key" production <<< "$value"
done
```

## Verify Setup

After adding variables:

1. Go to your Vercel project
2. Navigate to **Deployments**
3. Click on latest deployment
4. Go to **Runtime Logs**
5. Check for any environment variable errors

Or redeploy:
```bash
vercel --prod
```

## Notes

- Variables with `VITE_` prefix are exposed to the client
- Redeploy after adding/changing environment variables
- Use different values for Production vs Preview environments
- Never commit real credentials to git

For more details, see [ENV_VARS.md](./ENV_VARS.md)
